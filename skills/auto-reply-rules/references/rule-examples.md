# Rule examples

Starting points. Replace every bracket with the owner's own facts; drop any rule they don't need.

## Opening hours
- Applies to: comment, dm
- When: keyword "open" (add "hours", "timing", "مفتوح", "الدوام" for Arabic)
- Reply with: fixed: "We're open [hours]. See you soon!"
- Approval: ask me first at the start; skip later only if the owner agrees

## Location
- Applies to: comment, dm
- When: keyword "where" or "location" or "وين"
- Reply with: fixed: "We're at [address or area]. [map link the owner supplied]"

## "Link please"
- Applies to: comment
- When: keyword "link"
- Reply with: fixed: "Sent you a DM!" (comment) plus a DM rule with the owner's link, on networks where DM replies are supported (Instagram and Facebook)
- Note: never post the same link in many public comments; it reads as spam

## Price question
- Applies to: dm
- When: keyword "price" or "how much" or "كم"
- Reply with: ai (in the owner's voice), approval: ask me first
- Note: only if the owner's confirmed facts include prices; otherwise leave price questions for the owner

## Thank-you comments
- Applies to: comment
- When: any, for short praise
- Reply with: ai, approval: ask me first
- Note: keep a daily limit so replies don't look automated

## Never auto-answer (applies across all rules)
- refund, broken, damaged, late, never arrived, scam, lawyer, police
- partnership, collab, press, wholesale
- any message asking whether they are talking to a bot or a person
- any message with a phone number, address or order number
